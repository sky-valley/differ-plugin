# This repository is public

Everything here is world-readable: files, commit messages, PR titles, PR
descriptions, reviews and comments. Never write a secret, its name
(`GDIFFER_..._TOKEN` and the like), where it is kept (vaults, items or
secret-manager references), or how a credential is fetched or derived. Point at
"the private production runbook" and keep the details in gdiffer.
`test/public.test.mjs` fails CI on the common shapes in files. PR text and
comments have no check, so reread them before posting.
