# Differ creator plugin

This repository owns the public packaging, local helper, tests, and releases of
the Differ creator plugin. It does not own the hosted publisher or pagelike.

- Edit helper source in `helper/`, build tooling in `scripts/`, and package
  presentation in `scripts/build.mjs`. Run `npm run check` after changes.
- `plugins/differ/skills/` is a digest-verified snapshot from Control. Do not
  hand-edit it or its lockfile. Skill changes are authored in gdiffer's
  `services/control/internal/content/skills/`, deployed there, then imported
  with `npm run sync-skills`. External contributors can propose a documented
  change or open an issue; they do not need access to the private Control repo.
- `directory/differ/`, both sets of manifests, the helper bundle, and dependency
  notices are generated by `npm run build`. Commit them so installs work without
  builds. Never put development package manifests inside an installable plugin.
- Keep the local and directory distributions on the same version and skill bytes.
  They intentionally use different MCP transports and must not be co-installed.
- Every released change needs a version bump. See `docs/releases.md`.
- Use temporary directories and a local HTTP server for tests. Do not publish
  posts, connect a real account, or mutate production during ordinary tests.
- Do not commit tokens, guest journals, private claim links, reviewer credentials,
  or generated content. `differ-post.json` is public identity, not edit authority.
- Do not claim portal acceptance, account OAuth, or live behavior from package
  validation. Keep `docs/submission.md` explicit about external requirements.
- Commit and push completed, verified work. Never force-push shared history.
